# Electric-Potential-3D · 电势地形实验室

面向高中物理课堂的纯 HTML、CSS、JavaScript 和 Three.js 网站。无需 npm 安装，无需打包；Three.js 0.170.0 已放入 vendor，运行不依赖互联网。

## 运行（需要 Node.js）

在本目录打开终端：

```powershell
npm start
```

浏览器打开 http://127.0.0.1:8765 。保持终端运行，结束时按 Ctrl+C。不要直接双击 HTML，浏览器的模块安全规则可能阻止加载。需要支持 WebGL 的现代浏览器。端口被占用时先停止旧服务，或修改 server.js 中的 8765。

## 如何操作

拖动旋转，滚轮缩放，右键平移。选择单正、单负或等量异号案例；增加电荷后输入 q、x、y，画面立即更新。最多 8 个源电荷，q 范围 −5 至 5 nC，位置范围 −6 至 6 m。点击曲面读取该横向位置的平滑电势和电场大小。开关控制等势线和电场箭头；高度比例只影响图像，不改变物理读数。重置恢复所有初始设置。

电荷小球和等长电场箭头位于真实观察平面 z=0；等势线附着在电势曲面上。曲面被峰谷遮挡的部分可旋转查看。颜色固定按正负电势着色，超过 ±45 V 时颜色饱和，高度和读数仍使用实际平滑电势。有限网格峰顶可能略低于解析读数。

## 文件是做什么的？

- index.html：页面的骨架，放置按钮、读数与教学说明。
- style.css：页面的衣服，负责颜色、字体、排版和小屏幕适配。
- app.js：交互指挥员，创建 Three.js 场景、曲面、等势线、电场箭头，并响应操作。
- physics.js：物理计算器，用同一平滑模型计算电势与它的负梯度；输入 m、nC，输出 V、N/C。
- server.js：本地文件服务，把页面送到浏览器。监听局域网地址，仅提供页面所需文件。
- physics.test.js：验证电势正负、叠加、双电荷中点与电场负梯度关系。
- vendor/：本地保存的 Three.js、轨道控制器及 MIT 许可证。
- package.json：提供 npm start 和 npm test 两个快捷命令。

## 物理近似

理想模型 φ=Σkq/r，r 是真实三维距离。所有源电荷与观察点均在 z=0，所以本例 r²=(x−xᵢ)²+(y−yᵢ)²。可视化改用 √(r²+0.35²)；这会修改近场，并使电荷中心电势有限、电场为零，不应将中心附近读数当作理想点电荷结果。观察平面之外的三维电场不在本版显示范围内。地形高度不是实际空间位置，也不参与距离计算。

电势与试探电荷无关，电势能为 q₀φ，受力为 q₀E。负试探电荷改变受力方向，不改变电场方向。电势零点在无穷远，图中不将边界强行设为零。

运行 `npm test` 执行物理验证。Three.js 文档：https://threejs.org/docs/



## 手机访问
电脑运行 npm start，手机与电脑连接同一个可互通的局域网。输入终端打印的“手机访问”地址。不能在手机使用 127.0.0.1，这个地址指向手机自身。
单指旋转，双指缩放/平移，轻触曲面读取数值。向下滚动编辑电荷。
电脑需保持开机、终端保持运行。无法连接时检查 Windows 防火墙是否允许 Node.js 在专用网络接收连接，以及路由器是否开启访客/客户端隔离。校园网或单位网可能禁止设备互访。切换网络后 IP 可能改变，请重新查看终端输出。
服务监听 0.0.0.0:8765。此方式仅供局域网访问，手机使用移动数据或其他网络无法连接。
